SmartMart Product Search

Sistem pencarian barcode produk supermarket menggunakan perbandingan algoritma Linear Search dan Binary Search.

🔎

Cari Produk

Contoh barcode: 1708 untuk mencari Kornet Sapi Pronas
📚 Informasi Algoritma

🟠 Linear Search

Linear Search memeriksa data satu per satu mulai dari posisi pertama sampai barcode yang dicari ditemukan.

Pada pencarian barcode 1708, algoritma ini membutuhkan 35 perbandingan.

🔵 Binary Search

Binary Search memeriksa data bagian tengah, kemudian mempersempit area pencarian ke bagian kiri atau kanan.

Karena data barcode sudah terurut, pencarian barcode 1708 membutuhkan 6 perbandingan.
