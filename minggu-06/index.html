03 — SOURCE CODE

Inside Bubble Sort.

Inti algoritma yang membandingkan dan menukar nilai bersebelahan.

function bubbleSort(data, ascending = true) { const hasil = [...data]; for (let i = 0; i < hasil.length - 1; i++) { let swapped = false; for (let j = 0; j < hasil.length - 1 - i; j++) { const salahUrut = ascending ? hasil[j].nilai > hasil[j + 1].nilai : hasil[j].nilai < hasil[j + 1].nilai; if (salahUrut) { const temp = hasil[j]; hasil[j] = hasil[j + 1]; hasil[j + 1] = temp; swapped = true; } } if (!swapped) break; } return hasil; }
✿ Kesimpulan Bubble Sort mengurutkan data dengan membandingkan nilai yang bersebelahan. Ascending menghasilkan urutan nilai terkecil ke terbesar, sedangkan descending menghasilkan urutan terbesar ke terkecil. Kompleksitas waktu rata-rata dan terburuk adalah O(n²).
