02 / Algorithm Flow

Alur Logika Program

Langkah-langkah yang dilakukan algoritma Bubble Sort.

01 · Mulai

Siapkan array berisi nama dan nilai mahasiswa.

02 · Bandingkan

Bandingkan nilai mahasiswa pada posisi bersebelahan.

03 · Tukar Data

Jika urutan tidak sesuai, tukarkan posisi kedua data.

04 · Ulangi

Ulangi perbandingan sampai tidak ada data yang perlu ditukar.

05 · Tampilkan

Tampilkan data yang sudah terurut sesuai pilihan pengguna.

06 · Selesai

Pengurutan selesai dan hasil dapat diperiksa pada tabel.

03 / Source Code

Logika Bubble Sort

Berikut inti algoritma yang digunakan dalam program.

function bubbleSort(data, ascending = true) { const hasil = [...data]; for (let i = 0; i < hasil.length - 1; i++) { for (let j = 0; j < hasil.length - 1 - i; j++) { const perluTukar = ascending ? hasil[j].nilai > hasil[j + 1].nilai : hasil[j].nilai < hasil[j + 1].nilai; if (perluTukar) { const sementara = hasil[j]; hasil[j] = hasil[j + 1]; hasil[j + 1] = sementara; } } } return hasil; }
Kesimpulan: Bubble Sort mengurutkan nilai dengan membandingkan elemen yang bersebelahan. Ascending mengurutkan nilai dari kecil ke besar, sedangkan descending dari besar ke kecil.
